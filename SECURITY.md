# Security policy

The 0.1.x line is supported. Review [the threat model](docs/THREAT_MODEL.md) before executing deliberately hostile code. Docker isolation is not an escape-proof multi-tenant boundary.

Report vulnerabilities privately using this repository's GitHub **Security → Report a vulnerability** feature when available. If private reporting is not enabled, contact the repository owner through their published GitHub profile contact channel to arrange confidential disclosure. Do not post exploits, credentials or submitted private code in public issues. Include affected versions, platform, minimal safe reproduction and observed impact. No response-time or bounty commitment is implied.

Routine bugs and documentation issues may be public. Dependency and runtime image updates require the same policy and execution regressions as application changes.
